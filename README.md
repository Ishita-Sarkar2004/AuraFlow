# AuraFlow ✨ — Personal Growth & Productivity Suite

> A dynamic, responsive web application designed to merge goal management, financial tracking, personal care routines, and health analytics into one seamless sanctuary.

---

## 🌟 Key Features

* **⚡ Task & Productivity Suite:** Goal tracking, habit streak counters, and an interactive schedule planner.
* **💸 Finance & Budget Engine:** Income/expense logging, investment portfolio tracking, and emergency savings target calculator.
* **🌸 Wellness & Lifestyle Suite:** 
  * Adaptive Skincare, Haircare, and Grooming routine checklist.
  * Customizable Workout Routine & Fitness Tracker.
  * Hydration counter with dynamic progress bar and daily calorie logging.
  * Anatomical body measurement & BMI tracking.
* **📊 Multi-Metric Chart Analytics:** Real-time visual progress tracking powered by Chart.js.
* **🤖 Aura AI Habit Coach:** Interactive AI simulator offering productivity & mindset recommendations.
* **💾 Local Data Persistence:** Integrated HTML5 LocalStorage with automatic image compression for user avatars and CSV data export capabilities.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Flexbox & CSS Variables)
* **Scripting & State:** Vanilla JavaScript (ES6+)
* **Data Visualization:** Chart.js
* **Version Control & Hosting:** Git, GitHub, GitHub Pages
